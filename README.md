# Tech Stack Recommender

A simple Artificial Intelligence project that recommends suitable career roles based on a user's technical skills.

This project is part of **Artificial Intelligence Project 3 — AI Recommendation Logic**.

The main idea is simple:

> User enters skills → System compares them with job roles → Similarity is calculated → Top 3 career roles are recommended.
